Passwords

Access to the board from the network.

Root password

The password of the root user: SSH, the serial console and the web terminal. Out of the box it is root; change it before the board goes on a shared network.

The root password is still the default root: anyone who knows it can log in to the board over SSH and the web console.

The passwords do not match

Jupyter password

Jupyter (Python programming, /jlab) runs as root: its terminal and notebooks control the whole board. Without a password anyone on the network can open it. With a password Jupyter asks for it once per browser.

The passwords do not match
