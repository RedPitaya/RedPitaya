Panels. Same construction as the IN and OUT dialogs: a back arrow with the title, fields as setfield inputs, choices as justified button groups, the gain list as a styled select.

Menu. TEC and DETECT sit at the bottom, next to CURSOR and MEAS, and open in place of the menu.

Bar. Spans the plot and never overlaps the menu: detector temperature, setpoint, preamplifier output, controller state, and on the right the trend button with the state of the ptcc_control service.

Trend. Folded away by default. T_DET and U_OUT share the time axis, each scaled on its own, five minutes kept by the page.

Ranges. Each input is bounded by the USER_MIN / USER_MAX the attached module reports, so a value the firmware would silently clamp is refused before it is sent. Gain is a list because the module accepts a fixed set and answers ERANGE for anything else.

A module without the programmable detection part keeps the DETECT entry, with the controls replaced by one line saying so.
